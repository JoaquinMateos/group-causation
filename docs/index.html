Welcome to group-causation’s documentation!

Group Causation is an open-source Python library for causal discovery on time series and groups of time series. It provides tools for identifying causal relationships, automating benchmarks, and evaluating causal inference methods. The library is designed for researchers and practitioners in causal inference, machine learning, and time series analysis.

Features

  • Group Causal Discovery: Dedicated tools to uncover causal relationships across groups of time series.

  • Automated Benchmarking: Standardized evaluation of causal inference methods.

  • Seamless Integration: Designed to fit naturally into standard machine learning workflows.
